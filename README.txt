PAINEL COMERCIAL — STREAMLIT

1) Instale Python 3.11+.
2) Abra o terminal nesta pasta.
3) Execute:
   pip install -r requirements.txt
4) Depois:
   streamlit run app.py

O sistema reproduz a estrutura principal da apresentação:
- Identificação
- Meta/Faturamento/Projeção
- Histórico mensal
- Principais clientes
- Pipeline de negócios fechados
- Upcoming
- Exportação para Excel

A próxima etapa pode incluir a geração automática do PowerPoint preenchido usando o arquivo original como modelo.
